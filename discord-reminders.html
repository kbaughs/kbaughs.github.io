Case study  ·  Linden Lab

Making sure the team never misses a scheduled task

Our team tracked recurring work in a shared channel and calendar invites, and both only worked if someone remembered to check them. After a client event was missed, I built a reminder system that sends every task to the whole team right when it's due. We haven't missed a scheduled task since it launched.

The problem

A shared channel only works if someone checks it

Our team works every day of the year, and much of that work is recurring: daily checks, weekly payouts and reporting, and one-off dates for client events and planned changes. All of it lived in two places, a to-do channel in Discord and Google Calendar invites. If someone forgot to check either one, the task was missed.

That is exactly what happened. A client had a scheduled event that required our team to grant access and set up their audio stream beforehand. No one was reminded, the setup never happened, and the client's event suffered for it. Soon after, the same thing happened to a different client on another account. I came in a few days later to find the missed setup and disappointed messages waiting for us.

What I found

The tracking existed. The trigger didn't.

We weren't missing information. Every task was written down somewhere. The problem was that both systems waited for a person to go looking. On a busy day, nothing told the team a task was due, so the work depended entirely on memory.

Adding more channels or better notes would not have fixed that. The reminder had to come to the team, on schedule, without anyone needing to remember to look.

What I designed

How it works

The whole system runs inside tools the team already used every day. There is no separate server or hosted service to maintain.

  1. 1

    Config notecard

    Each reminder is one entry: what to post, and when.

  2. 2

    LSL script

    A script in Second Life reads the notecard and checks which reminders are due.

  3. 3

    Discord webhook

    Due reminders are sent straight to the team's channel.

  4. 4

    Team ping

    Each message tags the team's role, so no one has to go looking.

Design choices

Editable without code

I'm the only person on the team who reads code, so I chose a Second Life notecard as the input. The team already works in Second Life every day, and a notecard is plain text anyone can open and edit.

Pings the whole team

Every reminder tags the team's role instead of one person, so a task never depends on whoever happens to be online.

Four cadences

Daily reminders run every day to match a team that works all year. Weekly, monthly and date-specific reminders cover reporting, payouts and planned changes, with dates already set through 2027.

Checklists for multi-step tasks

Tasks with several parts, like launching a promotion, arrive as a list so each step is visible instead of buried in one line.

Step-by-step guide

Wrote instructions for adding and editing reminders, so the system doesn't live only in my head.

Tested with the team

Asked the team for thorough testing and feedback before we relied on it day to day.

How I built it

From standup to working tool in about two weeks

No one asked for a fix. I raised the problem in one of our standups and came back a week or two later with a working solution. I had been dealing with the same gaps every day, so I built the first set of reminders from what already lived in our to-do channel and calendar invites, then put the team on testing it.

I prototyped the first version with AI assistance, then wrote and edited much of the code myself. I maintain and extend it weekly, adding reminders and adjusting schedules as our work changes.

Results

No missed scheduled tasks since launch

Since the system went live on October 3, 2026, the team hasn't missed a scheduled task. Daily checks, weekly payouts and reporting, and one-off dates like company meetings all arrive on time, and reminders for changes later in the year are already set and waiting. My manager has praised the system, and it's now part of how the team runs every day.

What I'd improve next

Make it easy for everyone to edit

Even with the guide, the notecard format still feels intimidating to my teammates, so I handle most of the updates. That makes me a single point of failure. Next, I'd add a fill-in-the-blank template for each reminder type and walk the team through adding one live, so anyone can keep it running without me.

What this shows

When work keeps getting missed, the problem often isn't that people forget. It's that the system waits for them to remember. Sending the reminder to the team, on schedule, fixed what more channels and invites could not.
